# رایحه‌نو | فروشگاه سه‌بعدی عطر

نسخه‌ی استاتیک و آماده‌ی انتشار روی GitHub Pages؛ ساخته‌شده با HTML، CSS، JavaScript، Three.js و GSAP/ScrollTrigger.

## اجرای سریع

فایل `index.html` را در مرورگر باز کنید. برای تجربه‌ی کامل سه‌بعدی، اتصال اینترنت لازم است؛ Three.js، GSAP و فونت Vazirmatn از CDN بارگیری می‌شوند.

## انتشار روی GitHub Pages با گوشی

1. یک مخزن عمومی در GitHub بسازید؛ نام پیشنهادی: `rayeh-no`.
2. فایل‌ها و پوشه‌های همین پروژه را در ریشه‌ی مخزن بارگذاری کنید؛ ساختار باید شامل `index.html` و پوشه‌ی `assets` باشد.
3. در مخزن وارد `Settings` و سپس `Pages` شوید.
4. در بخش `Build and deployment`، گزینه‌ی `Deploy from a branch` را انتخاب کنید.
5. شاخه‌ی `main` و پوشه‌ی `/(root)` را انتخاب و `Save` کنید.
6. پس از پایان انتشار، نشانی عمومی به شکل `https://USERNAME.github.io/rayeh-no/` خواهد بود.

## امکانات فعلی

- صحنه‌ی سه‌بعدی بطری با هندسه‌ی ساخته‌شده در Three.js (مدل GLB خارجی لازم نیست).
- تغییر محصول و چرخش وابسته به اسکرول با GSAP ScrollTrigger.
- چرخاندن بطری با لمس/کشیدن انگشت یا ماوس.
- سبد خرید نمایشی با نگهداری محلی در مرورگر.
- فرم ثبت سفارش و صفحه‌ی شبیه‌سازی‌شده‌ی اتصال به درگاه؛ هیچ پرداخت واقعی یا ارسال اطلاعات به سرور انجام نمی‌شود.
- طراحی فارسی، راست‌چین و واکنش‌گرا.

## نکات مهم

- قیمت‌ها و نام عطرها نمونه هستند و باید با محصولات واقعی جایگزین شوند.
- سبد خرید فقط در همان مرورگر و دستگاه ذخیره می‌شود؛ سفارش به مدیر فروشگاه ارسال نمی‌شود.
- برای نمایش Three.js، GSAP و فونت، اینترنت و دسترسی به CDNها لازم است.
- GitHub Pages برای سایت استاتیک است و بک‌اند/پایگاه داده ارائه نمی‌کند.
